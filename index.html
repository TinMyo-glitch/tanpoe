📤 ကိုယ်ပိုင်ပို့

ဖုန်းချင်း ဖိုင်ပို့ — ဖိုင်က Server ထဲ မဝင်ဘဲ ဖုန်း ၂ လုံး တိုက်ရိုက်သွားသည်
Server က ချိတ်ဆက်မှု လက်ဆွဲနှုတ်ဆက်ရန်သာ (Signaling)

⚠️ ဒီ page ကို HTTPS link (GitHub Pages / Cloudflare Pages) ကနေ ဖွင့်မှ Camera နဲ့ ချိတ်ဆက်မှု အလုပ်လုပ်ပါမည်။ ဖိုင်ကို တိုက်ရိုက်ဖွင့်ရင် မရပါ။
⚪ မချိတ်ရသေးပါ

💡 နည်း ၁ (QR) — Internet မလိုပါ။ ဖုန်း ၂ လုံး Hotspot/Wi‑Fi တစ်ခုတည်းမှာ ရှိရပါမည်။
💡 နည်း ၂ (Code) — ဖုန်းတွေ ဝေးနေလည်း ရသည်။ ချောစုရဲ့ ကိုယ်ပိုင် Signaling Server (Apps Script သို့မဟုတ် Cloudflare Worker) လိုပါသည် — Setup ကို page အောက်ဆုံးမှာ ကြည့်ပါ။

🔗 ချိတ်ဆက်ရန်

ဒီ QR ကို တစ်ဖက်ဖုန်းနဲ့ Scan ဖတ်ခိုင်းပါ။ QR ကြီးလွန်းလို့ ဖတ်မရရင် အောက်က စာသားကို Copy ကူးပြီး တစ်ဖက်ဖုန်းမှာ Paste လုပ်ပါ။

တစ်ဖက်ဖုန်းက ပြန်ပေးတဲ့ Answer ကို ဒီမှာ Paste လုပ်ပြီး ချိတ်ပါ —

ပို့မယ့်ဖုန်းရဲ့ Offer QR ကို Scan ဖတ်ပါ (သို့) Offer စာသားကို Paste လုပ်ပါ။

ဒီ Answer QR / စာသားကို ပို့မယ့်ဖုန်းဆီ ပြန်ပေးပါ။

ဒီ Code ကို တစ်ဖက်ဖုန်းကို ပြောပြပါ (Code သက်တမ်း ၁၀ မိနစ်)

Network မတူရင် (ဥပမာ တစ်လုံး Wi‑Fi, တစ်လုံး Data) ဖိုင် ဖြတ်သန်းဖို့ Relay (TURN) လိုနိုင်သည်။ အခမဲ့ 20GB/လ — metered.ca/tools/openrelay မှာ Sign up → TURN credentials API link ကို ဒီမှာ Paste ပါ။
